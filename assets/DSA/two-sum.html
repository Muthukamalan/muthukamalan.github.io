Two Sum Visualizer

Find two numbers in an array that add up to a target, using a one-pass hash map.

Algorithm

function twoSum(nums, target) { const seen = new Map(); for (let i = 0; i < nums.length; i++) { const complement = target - nums[i]; if (seen.has(complement)) return [seen.get(complement), i]; seen.set(nums[i], i); } return []; }

Complexity

Time: O(n) — one pass through the array
Space: O(n) — the hash map may hold every element
Brute force would be O(n²)
