The Core Idea

Start with the widest possible container — one pointer at each end. Any container is bottlenecked by its shorter wall, so the width is the only thing working in your favor at first.

area = min(h[left], h[right]) × (right − left)

Checking every pair is O(n²). The two-pointer trick gets it down to O(n) with one key insight.

Always move the shorter pointer. Moving the taller one can only shrink the width while the height stays capped by the same short wall — that move can never beat the current area. Moving the shorter wall at least gives a chance at a taller line.

So at each step: compute the area, update the best seen, then step the shorter pointer inward. Repeat until the pointers meet.
