Why this matters in DSA

  • Check bit: (n >> i) & 1 — shift the bit of interest to position 0, mask off everything else with & 1.
  • Set bit: n | (1 << i) — OR with a 1 in that position forces it on, leaves the rest untouched.
  • Clear bit: n & ~(1 << i) — AND with all 1s except a 0 at position i forces it off.
  • Toggle bit: n ^ (1 << i) — XOR flips exactly that bit, leaves the rest alone.

Where it shows up

  • Subset enumeration: loop mask from 0 to 2^n - 1; each mask's bits mark which elements of an n-item set are included. Standard for bitmask DP.
  • Single number problems: XOR-ing all elements cancels pairs (a ^ a = 0), leaving the unpaired element.
  • Power of two check: n & (n - 1) == 0 clears the lowest set bit; a power of two has only one bit set, so this becomes 0.
  • Counting set bits: repeat n = n & (n - 1) and count iterations until n hits 0 — each step clears exactly one set bit.
